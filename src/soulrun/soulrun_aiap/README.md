# soulrun_aiap

V1.0.0 is the fixed pre-release version of the general AISOP execution runtime.
Website: https://soulrun.dev

Read `main.aisop.json` for the main actor and `agent_engine.aisop.json` for the
authorized child actor. Public node protocols and preserved predecessor evidence
are not renamed or rewritten. Qualification evidence identifies each candidate
by manifest SHA rather than by changing the public version.
